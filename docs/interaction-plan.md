# TNT 交互改造计划（基于 11/14 语音记录 + 自查）

> 状态：待用户确认后开工。P0 只动交互，不改数据模型（除新增 `deadline` 编辑入口，字段已有）。

## 一、用户提的问题 → 根因 → 方案

| # | 现象 | 现在的实现（根因） | 方案 |
|---|---|---|---|
| 1 | 调时间只能拖，容易误触、拉长费劲 | 方块按下即进入拖动；底部 20px 手柄常显；没有编辑面板 | 新增**方块编辑面板**：标题 / 起止时间 / 时长 / 优先级 / 截止时间 / 备注 / 删除。入口＝桌面右键、手机双击、以及选中条上的「编辑」。拖动保留为快速微调，但要过门槛（见 P0-4） |
| 2 | 完成按钮太小、位置不便 | 只藏在底部选中条里的一个 18px 图标 | 选中条右侧换成 **56×56 圆形主按钮**；手机放到拇指区（右下悬浮）。方块上**双击**也可完成（可关） |
| 3 | 优先级只能点小旗子，还常点不中 | `_SelectedBar` 里一个 18px 旗子，热区太小，和小图标排在一起 | 旗子**改为纯展示**（不可点，避免误触）；切换放进编辑面板的 A/B/C/D 分段 + 右键菜单 |
| 4 | 截止时间没入口 | 数据层有 `deadline`，UI 从来没有编辑入口 | 编辑面板加「截止时间」（日期+时间，可清除）；规则保持不变：A 恒置顶，B 且 ≤48h 才置顶 |
| 5 | 创建入口不清晰 | 只有「点空白处新建 30 分钟方块」这一条隐式路径 | 顶栏加 **`+` 新建**（当前位置/泳道，创建后直接打开编辑面板）；「点空白新建」进设置开关，默认**开**但可关 |
| 6 | 双击调整时间不应是默认 | 目前双击没有绑定编辑，隐式手势是「点空白新建 / 长按删除」 | 所有隐式手势集中到**设置 → 手势**：点空白新建、双击完成、长按删除（默认**关**，改为菜单里删） |
| 7 | 临时事件隐藏时应收掉那一栏，而不是「平掉上方任务」 | 顶栏 filter 只控制置顶项是否在泳道里**重复显示**，切换时会整体重排，观感像内容被压扁 | 改为**空泳道自动折叠**：某泳道当天没有方块时整列收起，其它列均分宽度（有开关可关）。**需你确认**：你说的「临时事件隐藏」是指隐藏整个临时泳道，还是只隐藏置顶投影？ |
| 8 | 合集/长期任务要独立页面 | 合集只有底部面板（只能投入今天，不能建/改）；长期计划页在日历页 AppBar 里，藏得深 | 新增**库页面**（两个 tab：合集 / 长期计划）：增删改查都在这里；时间轴只负责当天细节 + 「投入」 |

## 二、手机端专项

| 现象 | 根因 | 方案 |
|---|---|---|
| 时间范围「转动时漂移」 | `moveBlock` 用**指针绝对位置**换算开始时间，拖动中只要 scroll 变了（自动滚边/惯性）方块就跳 | 改成**相对位移**：按下时记录 `grabOffset`（指针落在方块内的位置），移动时 `newStart = snap(oldStart + Δy/pxPerMin)`，拖动期间冻结除边缘自动滚动外的 scroll 变化 |
| 调整好的时间范围没锁定 | 手柄常显，选中态只在点别处才清 | 选中才显示手柄，点空白取消选中＝锁定；另加显式**锁定按钮**（点一下变锁形，再点解锁） |
| 长按拖动、双击编辑（现在是反的） | 现在按下即拖、长按＝删除 | 改成：**单击选中 → 双击/长按进入编辑；长按后拖动才是移动**（带 `HapticFeedback.mediumImpact` + 方块轻微抬起阴影），松手吸附 |
| 拖下面条改时长太繁琐 | 唯一改时长方式就是拖 20px 手柄 | 编辑面板里直接输入/步进时间；拖手柄保留给「原地微调」 |

## 三、我自查出来的优化建议（按性价比排序）

1. **撤销（Undo）**：移动/改时长/删除/完成/顺延都进撤销栈，SnackBar 给 5 秒「撤销」。误触成本从「手动改回」降到一下。
2. **拖动时间气泡**：拖动中在方块旁浮一个 `09:05 – 10:05`，松手前就知道结果。
3. **吸附可调 + 触感**：档位 1/5/15 分钟可设，吸附时 `selectionClick` 轻震；现在固定 5 分钟且无反馈。
4. **重叠引导**：拖到别的方块上时显示半透明落位预览，松手自动并列（现在并列是自动的，但用户看不见规则）。
5. **空状态引导**：当天没有任何方块时，中间给「新建一件事 / 从合集投入」两个按钮，而不是一片空网格。
6. **集合按日期投入**：现在只能投入今天；改成选日期（今天/明天/点选）。
7. **新增「复制到明天」**：右键菜单里一条，比顺延更符合「临时多天任务」的用法。
8. **桌面快捷键**：N 新建、E 编辑、Space 完成、Delete 删除、↑↓ 微调 5 分钟。
9. **删除不再用长按**：长按改成拖动/菜单，删除走菜单 + 可撤销，杜绝误删。
10. **缩放记住位置**：缩放后保持时间锚点（现在锚定指针但不记忆，切页面回来会回到「当前时间前 2 小时」）。

## 四、锁定模式（用户新增需求）

顶栏最右侧加**锁**按钮，一键把界面切成「只读浏览」：

- **锁定时**：不能拖动方块、不能拖手柄改时长、不能点空白新建、不能双击完成、不能长按/右键出菜单；
  **只保留**滚动、缩放、点方块查看（信息条只读、按钮置灰）。
- 锁定时右下角浮现一条「已锁定 · 只能查看」的小提示，3 秒淡出。
- 锁定时不弹「有 N 件事没做完」的顺延窗，改成解锁后再问（避免误点按钮改数据）。
- 状态**不跨重启记忆**：每次启动都是解锁态，免得「为什么点不动」。
- **长按拖动方块的手势保持不变**（用户明确要求），只修底层漂移 bug，不动交互。



不用写清单，按下面这些维度说一句就行，我会对照调：

- **拖动静不静**（一碰就跑 / 要按一会儿才动）
- **跟手程度**（手指移了方块慢半拍 / 跳着走）
- **吸附**（5 分钟太细，想要 15 分钟？/ 吸附时没有「咔」的感觉）
- **惯性滚动**（太滑停不住 / 太黏）
- **缩放**（滚轮/双指卡顿、缩放中心跑偏）
- **点击/误触**（点空白就新建太容易、点方块没反应）
- **震动/音效**（要不要、哪些操作要）

默认打算：拖动门槛 6px + 吸附 5 分钟 + 轻震 + 惯性 friction 0.02→0.05（更跟手、不那么滑）。

## 六、第二轮自查：还能优化的操作逻辑

1. **顶栏图标太多**：现在 6 个（日历/集合/🔔/同步/历史/filter），手机上加锁就 7 个 →
   精简为 日历 / 集合 / 库 / 🔔 / 更多（更多里放同步、完成记录、置顶开关、锁定），图标热区统一 ≥44px。
2. **切日期太慢**：手机上只能点左右小箭头 → 时间轴支持**横向滑一天**（滑动松手后回弹，不误触方块）。
3. **点空白就新建太容易**：改为**长按空白才新建**，单击空白＝取消选中/收起面板；锁定态下都无效。
4. **跨泳道太灵敏**：现在方块中心 x 落到哪条泳道就换到哪 → 改成需**超过泳道宽度 40%** 才换，避免擦边跳列。
5. **选中后看不到**：选中/拖动时自动滚动，保证方块完整露出来（现在可能被底部信息条挡住）。
6. **单条顺延没有入口**：只有「有 N 件事没做完」弹窗能顺延 → 右键/长按菜单加「顺延到明天」「复制到明天」。
7. **刻度不随缩放变**：放大到 4x 还是每小时一行，太空 → 按 `pxPerMin` 动态显示 15/30/60 分钟刻度。
8. **当前时刻红线**：只在「今天」显示，看历史日期时不该出现（待确认现状，若不是就改）。
9. **系统手势冲突**：手机底部导航条会压住选中条 → 加 SafeArea，上滑区留白 12px。
10. **大字号溢出**：方块内标题/时间用固定字号，系统放大字体会溢出 → `maxLines + ellipsis` + 字号随高度收缩。
11. **首屏引导**：第一次打开给 3 步提示（拖方块 / 锁按钮 / + 新建），可跳过、只显示一次。
12. **列表一致性**：库页面里合集和计划都用同一套卡片样式（左色条＝泳道色），减少两种视觉语言。
